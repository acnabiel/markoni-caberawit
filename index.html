Status Database & Firebase

Panduan integrasi Cloud Firestore

Status Saat Ini: Terhubung

Aplikasi membaca dan menulis data ke Firestore project absensi-4d9c8 secara real-time.

💡 Aturan untuk Realtime Database (Sesuai Screenshot Anda):

Karena Anda membuka Realtime Database di Firebase Console, aturannya harus berformat JSON:

{
  "rules": {
    ".read": true,
    ".write": true
  }
}

Jika Menggunakan Cloud Firestore:

Buka menu Firestore Database → Tab Rules lalu gunakan rules_version = '2'; service cloud.firestore { match /databases/{database}/documents { match /{document=**} { allow read, write: if true; } } }

Catatan: Jika koneksi Firebase offline atau dibatasi, sistem otomatis beralih ke Penyimpanan Lokal (LocalStorage) agar seluruh fitur CRUD tetap berjalan lancar tanpa error.
